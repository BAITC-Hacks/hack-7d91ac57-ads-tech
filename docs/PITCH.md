## Заготовленные ответы
1. **Чем лучше ChatGPT?** Числа из детерминированного движка, воспроизводимо, объяснимо, тесты. LLM только отвечает на вопросы через инструменты и видит агрегаты, не транзакции.
2. **Откуда данные?** Синтетика с реалистичной структурой (разрешено ТЗ), формат выгрузки 1С, загрузка реальных CSV без изменения кода. Пороги выбросов калибруются на реальной истории.
3. **Как ловите крупный разовый заказ?** Робастный z-score по медиане и MAD дневных продаж плюс правило «один клиент ≥ 60 % месяца при аномальном месяце». Транзакция не удаляется, а заменяется типичным объёмом, чтобы не занижать день. Тест: вброс 40× медианы меняет прогноз меньше чем на 10 %.
4. **Упущенный спрос?** Импутация по 28 дням до и после дефицита плюс явный коэффициент за 12 месяцев к уровню. Тест: с дефицитом потребность выше, чем по сырым продажам.
5. **Сезонность?** Индексы «факт/тренд» по месяцам, две итерации, сжатие при короткой истории. Освещение: ноябрь 1.35, июнь 0.67 восстановлены из данных. Прогноз считается по месяцам горизонта, а не средним.
6. **Почему не Prophet/ETS?** 24 месяца истории, объяснимость менеджеру, никаких тяжёлых зависимостей. Интерфейс движка позволяет заменить прогнозчик.
7. **Приватность?** Клиенты только обезличенные ID, данные не покидают сервер, LLM получает агрегаты по позиции.
8. **Что если ошибётся?** Обоснование по каждой строке, редактируемое количество, утверждение человеком, автоотправки нет по ТЗ.
9. **Сколько стоит и как быстро?** Расчёт 72 позиций ≈ 1.5 с на ноутбуке, без LLM. Внедрение: CSV из 1С сегодня, коннектор к 1С следующий шаг.

## Демо-скрипт (90 сек)
1. Дашборд открыт, склад «Главный». Нажать «Рассчитать»: сводка, таблица по поставщикам, бейджи срочности. (15 с)
2. Раскрыть LMP-011: обоснование, график с маркером разовой продажи. (20 с)
3. Раскрыть TLS-010: заштрихованный дефицит, «учтён упущенный спрос». (15 с)
4. Ассистент: «почему по LMP-012 такое количество?» → шаг explain_sku, ответ, latency. (15 с)
5. Изменить количество, «Утвердить», «Экспорт XLSX» → открыть файл. (25 с)
Запасной план: видео 60 с; при падении сети DEMO_MODE уже включён.
