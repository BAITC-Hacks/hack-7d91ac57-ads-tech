# Питч (Demo Day, 29.09) — структура под рубрику жюри

Тайминг: 3–5 минут + вопросы. Каждый блок закрывает критерий.

| # | Слайд | Критерий (баллы) | Что сказать |
|---|---|---|---|
| 1 | Проблема | Ценность (25) | Кто, какая боль, масштаб в цифрах. Одна история одного пользователя. |
| 2 | Решение в одной фразе | Ценность (25) | «X для Y, который делает Z с помощью агента». |
| 3 | Живое демо | Результат (20) | Основной сценарий от входа до результата. Не более 90 сек. Запасное видео. |
| 4 | Как работает | Инновационность (15) | Схема агента: какие инструменты, почему агентный подход даёт то, что не даёт обычный чат. |
| 5 | Чем отличаемся | Инновационность (15) | 2–3 очевидные альтернативы и наше преимущество. |
| 6 | Масштабирование | Потенциал (20) | Следующие пользователи/организации/отрасли. Как деньги/эффект. |
| 7 | Что сделано за 5 часов и что дальше | Презентация (20) | Честно: сделано / не успели / план. |
| 8 | Команда + запрос | Презентация (20) | Кто что делал. Что нужно для следующего шага. |

## Вопросы, которые точно зададут
- Чем это лучше просто ChatGPT? → ответ через инструменты/данные/интеграцию.
- Откуда данные и права на них?
- Что будет при ошибке модели (галлюцинации)? → валидация, человек в цикле.
- Кто платит и сколько стоит один запрос?
- Как это масштабируется на N школ/вузов/учеников?

## Демо-скрипт
1. Открыть UI на заранее заполненных данных.
2. Показать вход пользователя → действие → результат агента (шаги агента видны в боковой панели).
3. Показать «до/после» или метрику.
4. Резервный план: видео 60 сек, если сеть упала.
