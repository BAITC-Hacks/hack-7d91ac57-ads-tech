Экраны, по приоритету:
1. Главный экран «Расчёт заказов»: панель фильтров (склад, категория, уровень сервиса 0.90/0.95/0.98, период 7/14/30 дней) и кнопка «Рассчитать» → сводка (позиций, поставщиков, критичных/высоких/обычных, общее кол-во) → таблица, сгруппированная по поставщикам (аккордеон по поставщику: название, срок поставки, позиций, кол-во). Строка: артикул, наименование, категория, остаток, в пути, рекомендуемое кол-во (редактируемое поле), срочность цветным бейджем (critical красный, high жёлтый, normal серый), кнопка «почему».
